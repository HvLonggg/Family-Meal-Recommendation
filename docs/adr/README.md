# Architecture Decision Records

ADR ghi lại các quyết định kỹ thuật ảnh hưởng nhiều module. Mỗi ADR sử dụng trạng thái `Proposed`, `Accepted`, `Deprecated` hoặc `Superseded` và không được sửa nội dung quyết định đã accepted theo cách làm mất lịch sử.

## Template

```text
# ADR NNNN Tên quyết định

Status:
Date:
Owner:

## Context

## Decision

## Alternatives considered

## Consequences

## Security impact

## Migration impact

## Rollback plan
```
